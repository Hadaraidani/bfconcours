🔄 Convertisseur questions.ts → questions-migration.ts

Convertit automatiquement le format complexe vers un format simple pour Supabase

📋 Instructions rapides :

  1. Ouvrez src/data/questions.ts dans VS Code
  2. Sélectionnez tout le contenu (Ctrl+A) et copiez (Ctrl+C)
  3. Collez dans la zone "Entrée" ci-dessous
  4. Cliquez sur "🔄 Convertir"
  5. Téléchargez ou copiez le fichier généré
  6. Remplacez le contenu de src/data/questions-migration.ts
  7. Exécutez npm run migrate
